# Gradix quick start: instructors

## 1. Create an assessment
- **New assessment**: give it a title and, if you like, a one-line prompt ("Grade 9: photosynthesis").
- Add your material: upload a PDF, Word, PowerPoint, text file or a photo of your notes, or add a web link.
- Add question blocks: type (multiple choice, true/false, short answer, fill in the blank, matching), how many,
  seconds per question (30 or more) and marks. Turn on **adaptive difficulty** if you want it.
- **Save**. The learning objectives appear in a few seconds.

## 2. Check objectives and publish
- On **Objectives**, edit or remove anything that is wrong and set the weights.
- **Publish** in the languages your class needs (English, Urdu, Arabic, Persian). Each student gets a different
  question set testing the same objectives.

## 3. Enroll and set exam controls
- **Enroll** students by email or a whole group.
- On the assessment page, **Exam controls**: proctoring (off / log / warn / auto-submit), opening and closing time,
  latest start, option shuffling, extra time for individual students.

## 4. Results
- **Analytics**: each objective, hardest questions, each student's answers, integrity events; export CSV or Excel.
- **Print**: the same paper for everyone or different papers per student, PDF or Word, with an answer key.

## 5. Live quiz in class
- **Live sessions > New**: questions from your assessment or a quick AI set; turn on game mode or teams if you like.
- Show the code or QR (projector view), press **Start**, then **Show answer** and **Next**.
- Use **Quick poll** and the **exit ticket** at the end of the lesson.

Help: the **?** button at the top (help center, tour, feedback).
